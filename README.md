# ระบบจดขาย ร้านในโรงเรียน

เว็บแอปให้ร้านในโรงเรียนจดขายด้วยมือถือ แต่ละร้านเลือก **แบบของร้าน** ได้ 2 แบบ

| แบบ | ใช้กับร้านแบบไหน | หน้าจอ |
|---|---|---|
| **จดเฉยๆ** | ตักให้เลย อยากรู้แค่ว่าขายอะไรไปเท่าไหร่ | กดเมนู → กด **เงินสด** หรือ **โอน** = บันทึกการขายทันที · แท็บ **ขายวันนี้** · **สรุปยอด** |
| **จดเพื่อทำ** | ต้องทำทีละชาม คนต่อแถวเยอะ | จดออเดอร์ → แท็บ **คิว** (แตะเสร็จทีละรายการ) · เปิดให้นักเรียนสแกนสั่งเองผ่านมือถือได้ |

ร้านที่มีตอนนี้ (แก้ได้ใน `shops.js`)

| รหัสร้าน | ร้าน | ค่าเริ่มต้น |
|---|---|---|
| `khaomoo` | ข้าวขาหมู หมูแดง หมูกรอบ | **จดเฉยๆ** · ทานที่ร้านอย่างเดียว · ไม่มีสั่งผ่านมือถือ · เมนู 6 อย่าง (ข้าวขาหมู, ข้าวหมูแดง, ข้าวไก่ทอดซอสมะขาม, ข้าวหมูแดง+หมูกรอบ, ข้าวหมูกรอบ, ข้าวไก่ย่าง) ตัวเลือก พิเศษ / ใส่ไข่ — **ราคายังเป็นราคาตัวอย่าง** |
| `noodle` | ก๋วยเตี๋ยว | **จดเพื่อทำ** · มีกลับบ้าน · นักเรียนสแกนสั่งเองได้ |

แบบของร้าน, มี "กลับบ้าน" หรือไม่, เปิดให้สั่งผ่านมือถือหรือไม่ เปลี่ยนได้ในแอป: **ตั้งค่า → ร้าน**

**การจ่ายเงิน:** นักเรียนสแกน **QR พร้อมเพย์ที่ป้ายหน้าร้าน** เหมือนเดิม แอปไม่ต้องรู้เลขบัญชี
(ถ้าอยากให้หน้าสั่งผ่านมือถือขึ้น QR ยอดพอดีเอง ใส่เลขพร้อมเพย์ในตั้งค่าได้ ไม่บังคับ)

**สรุปยอด:** วัน / 7 วัน / **เดือน** / **ปี** · แยกเงินสด/โอน · เมนูขายดี · แตะแท่งกราฟเพื่อดูละเอียด · ส่งออก CSV
(รายเดือน/รายปีอ่านจาก "ยอดรายวัน" ที่เครื่องร้านบันทึกไว้ให้อัตโนมัติ เปิดดูทั้งปีได้เร็วและไม่เปลืองโควตา)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `app.js`, `staff.css` | แอปร้าน: จด / คิว หรือ ขายวันนี้ / สรุปยอด / ตั้งค่า / โปสเตอร์ QR |
| `order.html`, `student.js`, `student.css` | หน้านักเรียน (เฉพาะร้านที่เปิดสั่งผ่านมือถือ): เมนู → ตะกร้า → สั่ง → จ่าย → ติดตามสถานะ |
| `base.css` | สี ตัวอักษร ปุ่ม ที่ใช้ร่วมกัน (มีโหมดมืด) |
| `shops.js` | **รายชื่อร้าน + แบบของร้าน + เมนูตั้งต้น** |
| `model.js` | ตรรกะล้วน: ราคา ตัวเลือก เลขคิว สรุปยอด (รายวัน/เดือน/ปี) CSV และข้อความ QR พร้อมเพย์ |
| `data.js` | ชั้นข้อมูล หน้าจอเรียกข้อมูลผ่านไฟล์นี้เท่านั้น |
| `data-firestore.js` | ของจริง: Firebase Auth + Firestore + ออฟไลน์ |
| `data-demo.js` | โหมดทดลอง: เก็บในเบราว์เซอร์เครื่องนั้น ใช้ตอนยังไม่ใส่ค่า Firebase |
| `firebase-config.js` | **ค่า Firebase — แก้ไฟล์นี้ไฟล์เดียวตอนตั้งระบบ** |
| `firestore.rules` | กฎความปลอดภัย (พนักงาน vs นักเรียน) |
| `icons.js`, `qr.js`, `vendor/qrcode.js` | ไอคอน และตัววาด QR (qrcode-generator, MIT) |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA: ติดตั้งบนหน้าจอโฮม เปิดได้ตอนไม่มีเน็ต |

## ลองเล่นทันที (ยังไม่ต้องตั้ง Firebase)

## ตั้งค่า Firebase (ทำครั้งเดียว ~15 นาที — ของโปรเจกต์นี้ทำเสร็จแล้ว เก็บไว้เผื่อย้ายร้าน)

1. https://console.firebase.google.com → **Add project** (ไม่ต้องเปิด Google Analytics)
2. **Authentication** → Get started → แท็บ **Sign-in method** → เปิด **Email/Password** (พนักงาน)
   และ **Anonymous** (นักเรียนที่สแกนสั่งเอง — ถ้ายังไม่มีร้านไหนเปิดสั่งผ่านมือถือ ข้ามได้)
3. **Authentication** → แท็บ **Users** → **Add user** ใส่อีเมล + รหัสผ่านของร้าน
   - **สำคัญ:** ต้องเพิ่มอีเมลนั้นในรายชื่อพนักงานด้วย: **Firestore Database** → Start collection → Collection ID `staff`
     → Document ID = อีเมลตัวพิมพ์เล็กทั้งหมด (เช่น `owner@gmail.com`) → ใส่ field อะไรก็ได้ 1 ตัว (เช่น `name` = เจ้าของร้าน) → Save
     (กฎใน `firestore.rules` ให้เฉพาะอีเมลในรายชื่อนี้เป็นพนักงาน — ต่อให้ใครสมัครบัญชีอีเมลเองผ่าน API ก็เข้าข้อมูลร้านไม่ได้)
   - เพิ่มพนักงานคนอื่น: เพิ่มบัญชีใน Users + เพิ่มเอกสารใน `staff` · เอาออก: ลบเอกสารใน `staff`
4. **Firestore Database** → Create database → location `asia-southeast1` (สิงคโปร์) → **production mode**
5. **Firestore Database** → แท็บ **Rules** → วางเนื้อหาไฟล์ `firestore.rules` ทั้งหมด → **Publish**
6. ⚙ **Project settings** → Your apps → ไอคอนเว็บ `</>` → Register → คัดลอกค่า `firebaseConfig` มาวางใน `firebase-config.js`
7. เปิดแอปบนมือถือร้าน ล็อกอิน → เลือกร้าน → ครั้งแรกระบบใส่เมนูตั้งต้นให้เอง
8. ร้านข้าวขาหมู: เข้า **ตั้งค่า → เมนู** แก้ราคาให้ตรงของจริง (แตะชื่อเมนู → ราคา / ตัวเลือก พิเศษ, ใส่ไข่)

## Deploy

### แบบ A: Firebase Hosting (แนะนำ ได้ https ฟรี)

```bash
npm install -g firebase-tools
```

```bash
firebase login
```

```bash
firebase use --add
```

```bash
firebase deploy --only hosting,firestore:rules
```

ได้ลิงก์ `https://<project-id>.web.app` เปิดบนมือถือร้าน แล้ว "เพิ่มไปยังหน้าจอโฮม"

### แบบ B: GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดขึ้น repo → Settings → Pages → Deploy from a branch → `main` / `(root)`
2. ที่ Firebase → Authentication → Settings → **Authorized domains** เพิ่ม `<ชื่อผู้ใช้>.github.io`
3. กฎ Firestore ต้องวางเองในหน้า console (ข้อ 5 ด้านบน)

### อัปเดตแอปหลังแก้ไฟล์

เปลี่ยนค่า `VERSION` บรรทัดบนของ `sw.js` ทุกครั้ง แล้ว deploy ใหม่ เครื่องร้านจะได้ของใหม่ตอนเปิดแอปครั้งถัดไป

## วิธีใช้ที่ร้าน (สั้นๆ)

**ร้านแบบจดเฉยๆ (ข้าวขาหมู)**
- แตะเมนู 1 ครั้ง = 1 จาน แตะซ้ำ = เพิ่มจาน · เปลี่ยน **พิเศษ / ใส่ไข่** ที่แถบเหนือปุ่มเมนู (มีผลกับรายการที่ไฮไลต์)
- กด **เงินสด** หรือ **โอน** = บันทึกการขายทันที · กดผิด แตะ **แก้** ในแถบแจ้งเตือน หรือไปแก้ในแท็บ **ขายวันนี้**
- **ขายวันนี้:** ยอดวันนี้ จำนวนบิล/จาน แยกเงินสด/โอน · แตะบิลเพื่อเปลี่ยนวิธีจ่าย แก้ไข หรือยกเลิกบิล

**ร้านแบบจดเพื่อทำ (ก๋วยเตี๋ยว)**
- จดออเดอร์ (ทานที่ร้าน/กลับบ้าน, ชื่อลูกค้า) → **คิว** แตะรายการเมื่อทำเสร็จ · ติ๊กจ่าย เงินสด/โอน
- ออเดอร์ที่นักเรียนสั่งเองมีป้าย **QR** และเลข **Q1, Q2…** เข้ามาพร้อมเสียงเตือน
  นักเรียนสแกน QR พร้อมเพย์ที่ป้ายหน้าร้าน แล้วกด "ฉันโอนแล้ว" → การ์ดขึ้น **ลูกค้าแจ้งโอนแล้ว** → เช็คยอดในแอปธนาคาร แล้วกด **โอน**
- คนเยอะจนรับไม่ไหว: ปิดสวิตช์ **รับออเดอร์จาก QR** บนหน้าคิว

**สรุปยอด (ทุกร้าน):** เลือก วัน / 7 วัน / เดือน / ปี · ลูกศรเลื่อนช่วง · แตะแท่งกราฟเพื่อเจาะดู · **ส่งออก CSV**
(วัน = ทุกรายการ, 7 วัน/เดือน/ปี = 1 แถวต่อ 1 วัน พร้อมจำนวนที่ขายได้ของแต่ละเมนูและแถวรวม)

## โครงสร้างข้อมูล Firestore

- `shops/{shopId}` — ตั้งค่าร้าน: `name, short, mark, color, mode ('record'|'kitchen'), takeaway, qrOrdering, qrOpen, overdueMin, quickNotes[], promptpay, promptpayName, queue`
- `shops/{shopId}/menu/{id}` — `name, price, category, desc, color, options[], active, sortOrder`
- `shops/{shopId}/orders/{id}` — `number, dateKey, createdAt, items[], total, paid, payMethod, payClaimed, cancelled, source ('staff'|'qr'), type ('dine'|'takeaway'), name, history[]`
  - ร้านจดเฉยๆ: บันทึกเป็น `paid: true` + `payMethod` และทุกรายการ `served: true` ทันที
- `shops/{shopId}/days/{YYYY-MM-DD}` — ยอดรายวัน `sales, orders, items, cash, transfer, unpaid, qrCount, cancelled, byMenu{}` (เครื่องร้านคำนวณจากออเดอร์ของวันแล้วเขียนเอง ใช้ทำสรุป 7 วัน/เดือน/ปี)
- `shops/{shopId}/counters/{dateKey}` — ตัวนับเลขคิว Q ของการสั่งผ่านมือถือ
- ไม่เก็บข้อมูลส่วนตัวนักเรียน นอกจากชื่อเล่นที่พิมพ์เอง

## ความปลอดภัย (สรุปจาก `firestore.rules`)

- พนักงาน (อีเมล): อ่าน/เขียนทุกอย่างของร้าน · เปลี่ยนเลขออเดอร์และลบออเดอร์ไม่ได้ (ใช้ยกเลิกแทน เก็บประวัติไว้)
- นักเรียน (Anonymous): อ่านชื่อร้าน/เมนูได้ · สร้างออเดอร์ได้เฉพาะร้านที่เปิดสั่งผ่านมือถือและกำลังเปิดรับ · ตั้งตัวเองเป็น "จ่ายแล้ว" ไม่ได้
  · อ่านได้เฉพาะออเดอร์ของตัวเอง · กดได้แค่ "ฉันโอนแล้ว" · **ดูยอดขายของร้านไม่ได้**

## ทดสอบในเครื่องด้วย Firebase Emulator (ไม่แตะข้อมูลจริง)

```bash
firebase emulators:start --only auth,firestore --project demo-shop
```

เพิ่มผู้ใช้ทดสอบที่ http://127.0.0.1:4000/auth แล้วเปิด `http://127.0.0.1:5500/?emulator=1#khaomoo`

## ข้อจำกัดที่ควรรู้

- **แอปไม่ได้ตรวจสลิป** ร้านต้องเช็คยอดเข้าในแอปธนาคารเอง (ปุ่ม "โอน" ในแอปเป็นแค่การบันทึก)
- **เลขบิล/ออเดอร์ที่ร้านจด** คิดจากของวันนี้ในเครื่อง ถ้ามี 2 เครื่องจดพร้อมกันตอนออฟไลน์อาจได้เลขซ้ำ (ยอดเงินไม่ผิด)
- ยอดรายวันเขียนโดยเครื่องร้านที่เปิดแอปอยู่ ถ้ามีหลายเครื่องและเครื่องหนึ่งออฟไลน์จนข้ามวัน ยอดของวันนั้นจะถูกคำนวณใหม่ให้ตรงเมื่อเปิดแอปวันถัดไป หรือเมื่อเปิดดูวันนั้นในสรุปยอด
- โควตาฟรีของ Firestore ต่อวัน: อ่าน 50,000 / เขียน 20,000 ครั้ง ร้านในโรงเรียนใช้ไม่ถึง
